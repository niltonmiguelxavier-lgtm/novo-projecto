# Estado do projecto

## Incluído
- Interface React + TypeScript + Vite, adaptada a computador e telemóvel.
- Navegação visual entre resumo, transacções, integrações e definições.
- Cliente HTTP de base para futura API.
- Migração SQL inicial para PostgreSQL.
- Documentação de arquitectura e segurança.

## Ainda por implementar
- Autenticação real, recuperação de palavra-passe e permissões.
- Backend/API de pagamentos e ligação privada à base de dados.
- Integrações M-Pesa, e-Mola e cartões.
- Webhooks verificados, reconciliação, testes automatizados e monitorização.
- Deployment, domínio, revisão de segurança e requisitos legais.

Todos os números na interface são dados fictícios. Não processa dinheiro real.
